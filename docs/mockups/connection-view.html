Home (D:\Retro\sparc) stays one click away with the Home button.

  • Tabs are connections, colour-coded per machine (right-click a tab to change its colour). The x logs off cleanly and closes the tab (asks first if something is running). Machines lists everything saved, with Disconnect all.
  • Machine header: the file service and the command service connect separately, each with its own button. Here Telnet is not connected yet.
  • Local pane: tree with +/- rooted at the home folder. Leave home... asks for a path (type it or Browse...); Home comes back; Media lists removable drives attached now.
  • Two areas, one splitter: drag the bar to change the heights. Swap in the machine header puts the terminal on top. Both are remembered per machine.
  • Folder trees collapse with the button at the left of each pane header (Ctrl+Shift+1 / 2), giving the list the full width.
  • Right-click a file -> Preview: reads only the start of a remote file; the viewer comes from the extension rules (Configure... in the preview window).
  • Right-click a folder: Archive as .tar.gz / .tar.Z runs on sparc through rsh when it has the tools, or inside legcon when it has no command service. The exact command is always shown first, editable, with Copy / Paste into Shell tab / Run once.
  • Edit and New file (right-click empty space): an editor inside legcon; Save writes back to the machine. No external programs, no mounts.
  • Settings in the machine header: that machine's services, home folder, layout, charset, crypto, host keys and credentials.
  • Terminal area (1/4 by default): Shell (Connect button until used), Console (protocol commands and one-shot commands), Log, Transfers.
