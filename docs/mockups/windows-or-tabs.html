Mockup 2: a connection as a tab or as its own window (O8)

Three machines connected: sparc, win95 and indy. Each connection is the same connection view (files on top, terminal below) either way. The question is only where it lives.

A. One window, a tab per connection; drag a tab out for its own window recommended

New connections open as tabs in the main window. Dragging a tab out (or "Open in new window") gives that machine its own window, here indy; dragging it back docks it.
  • One place to see every connection (the tab row and the Machines tab).
  • A second monitor can hold a shell-heavy machine on its own.
  • Tab dragging between windows is extra Win32 work (custom tab control).

The Machines window is the launcher; each connection opens its own window, found through the taskbar and Alt+Tab.
  • Simplest to build on Win32; each window is independent.
  • The OS window manager does the arranging (Snap, monitors).
  • Many windows with identical chrome; easy to lose one, and Disconnect all is in another window.
